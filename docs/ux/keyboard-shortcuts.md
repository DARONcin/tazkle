# Atajos de teclado

## Descubrimiento

- Apartado `Perfil y configuración → Atajos de teclado`.
- Buscador por comando y contexto.
- Atajo visible en menús y tooltips.
- Paleta de comandos con `⌘K`.
- Hoja rápida con `⌘/`.
- Detección futura de conflictos antes de permitir personalización.

La primera versión usa atajos predeterminados y no personalizables.

## Propuesta inicial

| Acción | Atajo |
|---|---|
| Paleta de comandos | `⌘K` |
| Buscar | `⌘F` |
| Nuevo bloque | `⌘N` |
| Conectar bloques | `⌘L` |
| Duplicar | `⌘D` |
| Eliminar selección | `⌫` |
| Deshacer | `⌘Z` |
| Rehacer | `⇧⌘Z` |
| Mostrar u ocultar sidebar | `⌃⌘S` |
| Mostrar inspector | `⌥⌘I` |
| Ajustar mapa a ventana | `⇧⌘F` |
| Referencia de atajos | `⌘/` |

Los atajos definitivos se validarán contra convenciones y comandos reservados de macOS durante el prototipo navegable.
