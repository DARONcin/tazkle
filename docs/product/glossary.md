# Glosario

- **Bloque:** registro estructurado con tipo, propiedades, estado, responsables y relaciones.
- **Relación:** conexión semántica entre dos bloques.
- **Lienzo:** representación visual del modelo del proyecto.
- **Expediente:** paquete aprobado de alcance, arquitectura, costos, riesgos y plan.
- **Perspectiva:** vista del mismo proyecto filtrada para un rol.
- **Variante:** alternativa completa del plan para comparar costo, tiempo, riesgo y capacidad.
- **Excepción documentada:** autorización explícita para continuar pese a una condición no satisfecha.
- **Tazki:** asistente de IA de Tazkle. Propone y explica, pero no autoriza.
- **Factibilidad:** evaluación multidimensional de si el proyecto puede ejecutarse bajo condiciones declaradas.
- **Cotización:** desglose del esfuerzo, costos, reservas y precio comercial.
- **Fuente central:** estado autorizado almacenado en Neon PostgreSQL.
- **Estado local:** copia SQLite que permite consulta y trabajo con conectividad limitada.
